# Changelog

## 0.1.0 — 2026-11-13

Initial release of OpenAI Usage for DeepSeek Harness.

- Chinese and English settings panel following the Harness interface language.
- Organization or project usage, cached input tokens, model breakdowns and request counts.
- Official costs, daily spending and charge-item breakdowns, including the current UTC day.
- Optional organization spending limit and a link to the official billing page for credit grants.
- Admin API Key configuration through Harness credentials; owner-only access.
- Authenticated shared Connection routes compatible with separate service contexts.
- Prebuilt installation package distributed through GitHub Releases; no npm publication.
